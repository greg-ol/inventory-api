# This is Gilded Rose Inventory API.

### Coded with Java 25 and Spring Boot 4 and Gradle.

In order to run API:
1. Build the jar out of Spring Boot application using Gradle `./gradlew bootJar`
2. Run the jar `java -jar build/libs/inventorymgnt-0.0.1-SNAPSHOT.jar`

Alternatively run Spring Boot application using Gradle:
1. Run using gradle  `./gradlew bootRun`

API runs on http://localhost:8081.

This API has got Swagger connected to it for demo purpose:
http://localhost:8081/swagger-ui/index.html
